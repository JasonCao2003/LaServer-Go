# 旧客户端游戏接口迁移任务

用户已明确开发旧客户端游戏接口，允许在现有 Ubuntu WSL 安装 Go 并运行本地测试。沿用已确认的 net/http、SQLite、独立 api-server 进程；不开发通用实体 CRUD 或 ENet 服务。

## 范围与执行顺序

- [x] 无副作用扫描旧路由注册，记录精确路径、方法、来源和迁移状态。
- [x] 为 SQLite 打开、显式初始化、旧库误用保护、账号登录/会话轮换、存档持久化和房间发现编写真实数据库集成测试，先记录失败。
- [x] 实现独立 api-server 启动与 migrate 子命令、参数和配置校验，数据库只通过显式初始化修改结构；配置路径相对配置文件解析。
- [x] 按旧代码实现 /account/create、/account/auth/create、/account/login、/account/auth/login；默认不自动授权，保留旧登录未授权 406 和封禁语义。会话、设备、recovery token 不写日志。
- [x] 实现 userdata/sync_user_data、货币与房间发现；存档空包不得覆盖已有数据。显式记录旧接口缺失会话校验与新实现的差异，不能默默沿用越权写入。
- [ ] 基于清单分批补齐其余读取、社交、购买和任务接口；每批先核对规则与副作用，再写兼容断言和实现。尚未实现的旧路径返回明确 501，未知路径 404，均不得伪装成功。
- [x] 完成可复现的本地测试、静态检查和 Windows/Linux 构建验证，更新覆盖报告及启动说明；实际客户端验收与真实数据迁移另行授权。

## 验证重点

text/plain JSON、空/畸形/多段/超大请求；设备反查旧登录；授权与永久/过期封禁；无效会话；存档重启恢复及空心跳；同账号数据隔离；无实时服务时 API 可启动；未知接口不返回成功；错误不泄露数据库路径或凭据。

## 环境

Go 用户目录工具链 ~/.local/opt/go1.27.4，缓存使用 WSL Linux 文件系统，不重复复制源码。仅用隔离数据库；不修改旧实例、旧配置和旧项目未提交代码。文档为接口阶段执行记录，不代表所有接口已完成。
