# API Server 下一阶段实施计划

> **For agentic workers:** 按任务逐项实施并记录证据；每项的完成条件是可复现的行为验证，不以路由存在或 HTTP 200 代替。

**Goal:** 将已接入的游戏 HTTP 路由推进到可核验的协议、状态和客户端兼容基线，并明确 API 自身与实时服务的交付边界。

**Architecture:** 保持独立的 `api-server` Go module，沿用 handler → service → repository 和 SQLite 迁移。先建立完整路由及登录资源证据，再修复具体差异；跨服务在线状态和推送通过明确协议与独立 `room-server` 对接，两个服务仍能分别启动。

**Tech Stack:** Go 1.26+、`net/http`、`database/sql`、`modernc.org/sqlite`、Go `testing`；不引入 Redis 或 MySQL。

**Spec:** [重构设计](../specs/2026-11-11-go-rewrite-design.md)、[复刻 TODO](../../TODO.md)、[测试覆盖计划](2026-11-12-api-test-coverage.md)、[旧路由清单](../../../json/api/legacy-routes.json)。

## 审查结论（2026-11-13）

- `services/api-server/internal/handler/api.go` 已注册静态清单中的 201 条路径；`docs/TODO.md` 与路由清单记录待迁移为 0。这只说明静态路由入口已接入。旧服务的装饰器、动态注册、Socket.IO、WebSocket 和 MQTT 不在该数字内，尚缺完整盘点。
- A、C、D 批已有逐入口自动化测试；B 批已有交易和任务闭环测试，但尚未逐入口对照。最近一次完整 Go 回归记录 129 条 `pass` 事件、0 `fail`，并通过 vet/build；事件包含包与子测试，不能解释为 129 条路由通过。真实 APK 验收未完成。
- `api-server` 可独立运行，schema 到 v17；登录仍可仅凭 user ID 获取会话，不能作为公网身份校验。旧实例数据没有导入工具；消息队列仅在单个进程内；在线状态、管理推送、公寓在线状态与真实预约未连接实时服务。部分旧接口本身只返回占位数据。
- 结论：**静态 HTTP 入口迁移完成；API 服务整体开发未完成，也不能宣称可替换旧服务。** 本计划只安排 API 侧工作；`room-server` 实现继续由独立计划负责。

## 全局约束与验收口径

- 保留两个独立 Go module、独立进程和独立启动；API 不导入 room-server 的 internal 包，不用共享 SQLite 表交换实时状态。
- 旧数据只在隔离副本上分析；导入工具默认拒绝覆盖已有目标库。真实支付凭据未经验证不得发货。
- 每条路由分别记录入口、成功响应、失败响应、持久化副作用、版本和客户端证据。占位兼容响应明确标记为占位。
- 测试使用临时 SQLite 和临时文件；运行测试遵照用户的测试授权，日志放在项目 `logs/`。真机操作、截图和正式实例切换单独按项目约束执行。

## Task 2：收紧身份与登录协议兼容

- [ ] 对照旧服务和真实请求记录，列出 `auth/create`、`auth/login`、legacy create/login 的表单、BOM、恢复凭据、设备字段和错误分支；先写拒绝、跨账号、重试及过期会话用例。
- [ ] 确定可由 0.1.8/0.3.11 客户端提供并可由服务端核验的身份凭据，再实现认证策略。若旧客户端没有足够凭据，明确保留隔离开发模式和部署限制，不把 user ID 登录称为安全完成。
- [ ] 验收：协议分支与两版客户端证据一致；无法核验的登录模式不会被配置误认为公网安全模式。

## Task 3：补齐启动资源和版本差异

- [ ] 针对实际失败修复 service 层资源装配和版本过滤；对旧占位响应只保持兼容，不虚构业务能力。
- [ ] 验收：隔离实例的冷启动、登录、资源拉取不出现未解释的 404/501/500；每个资源有来源、响应合同及失败策略。

## 执行顺序

先完成 Task 1 的盘点和资源依赖，再按真实首个失败点推进 Task 2–3；Task 4 的数据库工作可在协议证据稳定后独立进行。Task 5 的 API 合同先于 room-server 联调，Task 6 最后验收。每完成一个可独立审阅的任务，检查 `git status` 和相关 diff，再决定是否建议提交；提交和推送需用户另行授权。
