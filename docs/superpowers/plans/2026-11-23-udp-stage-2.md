# UDP 第二阶段实施计划

依据 [UDP 房间服务设计](../specs/2026-11-23-udp-room-server-design.md)及[第一阶段记录](2026-11-23-udp-stage-1-results.md)。

1. 在 Windows Go 1.26.0 上先建立 0.1.8 的时钟 codec 回归用例。覆盖两种客户端头、显式布局、错误包长度和服务端 Pong 字节。样本基于旧源码和实测帧长度合成。
2. 实现独立配置、运行生命周期及传输边界。0.1.8 的候选必须通过实机 ENet 握手，0.3.11 的传输需求保持待实测。传输未完成时不发布伪造健康的入口。
3. 按第一阶段清单迁移各版本包头、JoinGame、控制包、GameMsg 和快照。为每个 profile 追踪旧实现差分结果。
4. 根据客户端回传证据定稿凭据载体后再接入 API 验证和会话。覆盖超时、重复连接、迟到认证、断线及依赖不可用。
5. 全量协议实现完成后执行各版本的实机协议验收。按项目规则单独确认测试和提交。
