# LaServer-Go 独立管理面板设计

日期：2026-11-24。已确认使用 Go 模板 Web 面板。本设计定义首版功能和接入边界，供实现前审阅。

## 框架与部署

采用 Go 标准库 `net/http` 和 `html/template`，通过 `embed` 随二进制分发模板与静态文件。表单使用服务端渲染，少量原生 JavaScript 用于交互增强。选择这一方案是因为首版主要是状态、查询和表单，独立二进制便于部署。已比较 Go + Vue 和 Python/Tkinter，前者适合复杂浏览器交互，后者适合本机桌面操作。

```text
services/admin-panel/
  go.mod
  cmd/admin-panel/main.go
  internal/panel/
    templates/
    static/
  config/admin-panel.example.json
  README.md
```

管理面板与 `services/api-server/`、`services/room-server/` 同级，拥有独立 Go module。从 `services/admin-panel/` 构建和启动。默认监听 `127.0.0.1:18080`，当前首版限定回环监听。面板进程独立运行，启动时只校验自身配置。API 或房间服务离线时首页仍能显示，页面上的服务状态随探测结果变化。面板通过 HTTP 与两个服务交互，SQLite 和账号写入由 API 管理。

## 首版页面与接口

旧面板作为功能参考，首版提供服务概览和好友管理。账号搜索、公告、封禁、内容管理需先具备对应管理接口。日志流、进程控制与源码发布单独设计。

| 页面或动作 | 调用 | 行为 |
| --- | --- | --- |
| 服务概览 | API `GET /healthz` | 200 显示在线，超时、拒绝连接和非预期响应分别显示 |
| 房间状态 | `GET /healthz`、`GET /readyz` | 健康与就绪分别显示；ready 503 表示尚未就绪 |
| 查询好友 | `POST /admin/api/friends_list` | 输入用户 ID 和可选关键字，展示好友 ID、昵称、备注及双向状态 |
| 增加、移除、恢复 | `POST /admin/api/friends_set` | 发送 `user`、`friend` 和枚举 `action`，回显业务结果 |
| 清空好友 | `POST /admin/api/friends_clear` | 二次核对用户 ID，分别展示移除数量和失败条目，刷新列表复核 |

面板同时检查 HTTP 状态和 JSON 的 `ok`，因为业务失败也可能返回 HTTP 200。清空可能部分成功，保留执行结果供人工核对。写请求超时后提示结果待确认，查询最新状态由管理员发起，避免自动重试变更。健康探针只用于判断对应 HTTP 服务状态。

## 配置、安全和错误处理

- 面板配置包含两个固定服务地址、监听地址及上游超时，启动时解析并校验。上游支持 HTTPS 或本机回环 HTTP。TLS 使用正常证书校验。请求使用固定路径、禁止自动跟随重定向，响应体有读取上限。
- 管理员登录和上游凭据分离。面板密码由环境变量提供，登录成功后使用随机服务端会话和 HttpOnly、SameSite Cookie，并设置过期时间。退出清除会话。API 管理令牌由独立环境变量注入，面板服务端通过 `X-Admin-Token` 发送。API 也须显式配置同一令牌，避免依赖 API 的回环免令牌分支。
- 管理提交只接受 POST，检查会话、CSRF 令牌及来源。页面使用模板转义，好友昵称与备注按纯文本显示。例子、日志和页面可见内容均省略凭据。
- 表单校验允许的动作、空值、长度及清空确认。API 执行最终授权、事务与审计。面板日志记录动作、结果和请求 ID，便于联查；不输出密码、令牌、Cookie 或请求体。
- 远程管理部署另行设计认证和 HTTPS 入口。首版由有权限的操作者在本机浏览器访问。

## 实施顺序与验收

1. 建立独立 module、配置和服务生命周期。验收面板单独启动、两个上游均离线时页面可打开，以及退出后端口释放。
2. 实现状态页和登录。用 HTTP 测试服务器覆盖在线、未就绪、不可达、响应异常和超时。确认上游探测失败时仍可查看另一服务的状态。
3. 接入好友查询和写操作。用模拟 API 核对请求方法、字段、鉴权头、HTTP 200 业务失败和批量部分失败。覆盖未登录、无效 CSRF、清空目标不匹配和转义。
4. 在临时 SQLite 和测试账号上运行真实 API 与面板，核对好友增删恢复及清空结果。使用浏览器检查状态、表单、错误反馈和窄屏布局，并分别运行面板与 API 的测试、vet 和构建。
