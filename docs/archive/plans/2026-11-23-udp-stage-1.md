# UDP 第一阶段实施计划

**目标** 从旧服务提取迁移覆盖表，建立传输对照并确认两款实际 APK 的线上行为。

**设计** [UDP 房间服务开发设计](../../superpowers/specs/2026-11-23-udp-room-server-design.md)

1. 从 PacketIds、PacketDispatcher、版本矩阵和服务入口提取清单，写入 json/room-server/stage-1-inventory.json。区分包声明、处理器、静态构建扫描和实际联机证据。
2. 用已安装的 sky-enet 在回环地址检查 checksum、双通道、收发、分片和重连，将运行输出写入 logs/room-server。旧服务及依赖保持只读。
3. 核对实际 APK、设备 ABI、API 公告和本机网络。以隔离账号测试两个构建的握手、收发和重连。日志仅留脱敏元数据。
4. 对候选分别验证真实客户端和 Windows/Linux 构建。在证据满足后锁定依赖并记录选择。缺少环境或客户端证据时保留待验收。
