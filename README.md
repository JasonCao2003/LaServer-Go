# LaServer-Go

LaServer-Go 是旧 LaServer 的游戏服务端重构项目，面向旧版 Sky 客户端。它负责玩家登录、保存游戏进度、提供任务与社交功能，以及让玩家进入联机房间并同步场景内的状态。

## 玩家能使用哪些功能

| 功能 | 已实现的能力 |
| --- | --- |
| 账号与存档 | 创建账号、登录、读取和更新玩家资料，保存游戏进度、物品和货币。 |
| 游戏内容 | 提供任务、活动日程、地图和收藏品等游戏数据。部分内容需要实例提供相应的游戏配置。 |
| 好友与互动 | 支持好友邀请与关系管理，以及礼物和社交消息等互动。 |
| 交易 | 支持部分游戏内交易和发放流程。开发环境可显式开启模拟购买，真实支付凭据无法通过该流程发货。 |
| 实时联机 | 支持入房认证、玩家名册、离房通知和时钟同步。协议族 284 和 542 已实现同关卡状态同步，以及生物事件、亲和事件和音乐消息的转发。 |

## 实例管理与旧数据

- **日常运营**可通过管理接口查询和修改账号、维护好友关系、管理 IP 封禁，以及更新登录公告。
- **旧账号与存档**可先用导入工具只读盘点，再导入全新的数据库。可保留的数据范围以盘点结果为准，新实例也可以直接从空库开始。

## 客户端兼容进度

项目仍在开发中。现有验证记录覆盖旧版 0.3.11 客户端的单端入房和重连。双端状态同步、自然过图、Linux 上的真实客户端联机，以及 0.1.8 的完整流程仍待验收。不同版本的客户端可用功能以实际验证范围为准。

旧客户端使用 ID 或设备信息登录时，需要在隔离环境中显式开启旧版开发登录模式。默认登录模式使用恢复令牌。
